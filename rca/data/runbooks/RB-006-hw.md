# RB-006 Radio Hardware Fault

## Symptoms
Open HW_FAULT incident on the remote radio unit; module reset unsuccessful.

## Diagnosis
1. Identify the purchase order and batch of the installed radio unit.
2. Check whether other sites with the same batch have open HW_FAULT incidents (batch-level defect).

## Resolution
- Replace the unit from spares and return the faulty unit to the vendor under warranty.
- If more than one site shares the failing batch, quarantine the batch and raise a vendor quality incident.
